# 乔杰 基础信息与研究方向

## 基础档案

- 姓名: 乔杰
- 医院: 北京大学第三医院
- 科室: 妇产科

## 专业与任职

- 北京大学第三医院院长乔杰参加面向全球网络直播的中国新冠疫情防控经验国际分享交流会
- 中国工程院院士 北京大学常务副校长兼医学部主任乔杰同往常一样 已经在北京大学第三医院 以下简称北医三院 开始一天的工作
- 团队带头人为乔杰院士 现任中国科协副主席 北京大学党委常委 常务副校长 医学部主任 北京大学第三医院院长


## 核心研究方向

- 我 中心 于 2017年首次获批深圳市三名工程项目 引进了 北京大学第三医院生殖医学 乔杰院士女性生殖健康与生育力保护研究团队
- 研究新冠病毒对孕产妇及子代健康长期影响 探讨其对生殖系统 配子及胚胎发育影响将是后续重点研究方向
