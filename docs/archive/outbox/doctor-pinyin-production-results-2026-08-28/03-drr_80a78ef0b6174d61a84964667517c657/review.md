# 杨璐医生公开执业概况（北京协和医院皮肤科）

## 摘要

杨璐，医学博士，毕业于清华大学八年制临床医学专业，曾于2014\-2016年赴美国匹兹堡大学访问交流并进行基础医学研究，获北京协和医院优秀临床医学博士后、优秀住院医等荣誉称号。北京协和医院官网医师介绍（2022年发布）称其为皮肤科住院医师；好大夫在线页面（基本信息来自医院官网或公示信息）显示其为主治医师。其从事皮肤病及性病的诊疗及研究，以第一作者发表多篇中英文文章，并参与编译《皮肤性病学》《北京协和医院疑难重症皮肤病病例精讲》等专著。
