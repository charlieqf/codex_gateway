## 问题与改动

长期复用的全局 Ajv 实例会保留动态编译生成的校验函数；只删除 schema 缓存不能释放整个编译器引用图。现在按完整工具集合缓存独立编译器，限定最多 128 组、1024 个根 schema 和 2 MiB 序列化 schema；按集合淘汰编译器。序列化大小限制不是堆内存上限。

同组 schema 先注册 `$id`，保留前向及跨工具 `$ref`；按方言隔离编译。请求持有的工具通过 WeakMap 关联校验器，缓存淘汰不会破坏仍在执行的调用。两个各含 65 个工具的请求交替使用时复用完整集合，避免逐 schema 淘汰带来的重复编译。

已确认并修复这一保留缺陷，但没有生产 heap dump，不能断言它是历史 OOM 的唯一原因。旧容器在 2026-11-04 12:40:04 UTC 又记录一次 JavaScript heap OOM，随后自动重启；本次部署前累计重启两次。新版本的长期内存走势仍需后续真实负载验证。
