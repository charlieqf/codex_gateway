# 模型及图片分析错误提示改进

针对 2026-09-10 PPT 会话的图片分析失败，Gateway 将 OpenAI-compatible 模型适配器的
笼统 unavailable 提示改为本次操作的失败原因和下一步建议。
定位依据为 `req-16760922-c8c1-4637-bdb2-9972b883dfe1`：xAI vision 返回 HTTP 500，
Gateway 错误码为 `upstream_unavailable`。此前同会话的图片数量 413 是另一项限制。

## 用户提示

该次 HTTP 500 对应的新提示：

> 图片分析时发生处理错误，本次请求未完成。请稍后在当前对话中重试；如持续失败，请联系支持并提供请求编号。

| 已确认原因 | 提示开头 | 下一步 |
| --- | --- | --- |
| 上游 HTTP 5xx | 图片分析时发生处理错误 | 当前对话稍后重试，持续失败联系支持 |
| 响应超时，包括 HTTP 408/504 | 图片分析响应超时 | 当前对话稍后重试，持续失败联系支持 |
| 服务之间的网络或代理错误 | 图片分析连接异常 | 当前对话稍后重试，持续失败联系支持 |
| 上游认证或权限拒绝 | 图片分析服务的接入配置异常 | 联系支持，避免要求用户重新登录 |
| 其他无有效结果的适配器错误 | 图片分析未返回有效结果 | 当前对话稍后重试，持续失败联系支持 |

无图片输入时，操作名称为“模型处理”。图片分析不等同于独立的图片生成接口。
普通 HTTP JSON、Chat Completions SSE 和 Responses SSE 均传递此 message。
既有客户端读取响应文字，无需新安装包即可接收；旧 SDK 可能仍添加错误类型前缀。
历史已持久化的错误不会重写。

只调整上述错误文字，保留错误码、HTTP 状态、请求编号、失败分类和重试合同。
没有新增自动重试，也没有提高图片数量上限。额度、认证、上下文压缩等专用错误的
原有判断保持不变；不向用户回传上游原始响应、内部地址或凭据。
