## 服务行为

- 登录客户端调用 `/gateway/subtitles/v1/transcriptions` 提交音频并查询结果，Gateway 代持云端 ASR 凭据。
- `/gateway/subtitles/v1/clean` 根据当前对话传入的 `goldencode` 或 `goldencode-d`，复用既有公开模型注册表、适配器及账号池。仅接受本人转写任务的有限字幕批次。
- 固定规则清理显式使用 `low` 推理档和原生 JSON 输出。普通模型预算6,000 token，深度模型32,768 token，均服从模型上限。服务端单次等待300秒，客户端清理请求330秒；客户端内容校验最多触发一次修复。
- 字幕业务不创建 token 额度预留，既有业务策略不变。公司凭据不进入客户端安装包。
- 本地 Python 工具继续承担音频准备、原始 SRT 导出和审定 SRT 烧录，不修改工具源码。
