# Former Azure Controlled-Trial Archive

Status: retired.

The public internal trial previously documented here ran on the Azure
`codex_gateway_test` project and `gw.instmarket.com.au`. That deployment is no
longer a supported Gateway endpoint, authority, compatibility service or
rollback condition. The filename remains only to keep historical links valid.

Use the task-oriented [Runbook Index](./runbook-index.md) for current R760
operations. In particular:

- issue real-user keys through
  [MedEvidence Codex Key Provisioning](./medevidence-codex-key-provisioning.md);
- query usage or change users/keys/Plans through
  [R760 Control-Plane Authority](./r760-control-plane-authority.md);
- deploy through [R760 Container Deployment](./container-deploy.md).

The original trial commands, smokes and execution log remain in Git history.
They may be consulted only for an explicitly authorized historical recovery
task, after verifying the exact target and shared-host boundary.
