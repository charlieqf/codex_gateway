# Doctor Research 检索与恢复修复（2026-09-10）

用户提供的六例均使用原始中文机构、科室或职务输入，没有手工提供个人官网 URL；加测王永生原问题。修复覆盖 Research Worker 和 Research Agent，Gateway API 请求格式保持兼容。

## 原因与处理

- SerpAPI 请求错误被通用异常覆盖，丢失 timeout、HTTP 状态及可重试性质；搜索阶段尚未调用模型的失败又被排除在恢复条件之外。现在保留类型，记录脱敏的请求耗时、状态、query hash、search ID；局部失败不再停止整个 worker。历史王永生任务的原始异常已丢失，只能确认搜索阶段失败，不能断言当时 Google 没有结果或供应商宕机。
- 首轮候选存在不代表身份已核实。改为抓取正文后判断是否补搜；补充机构译名、科室译名、医院站内真实导航和经审阅的专业机构来源，并行抓取三路，证据足够即取消多余抓取。仍要求正文同时支持姓名、机构及专业；403、空壳页面不会成为证据。
- 中外混合输入也用于 PubMed 时，以经审阅的外文机构与专业别名参与检索及作者所属单位核验。行政职务中的妇产、母胎等临床方向可用于身份确认，具体“副院长”等任职必须另有来源支持。
- 成功但零结果、供应商处理中、异常响应分别分类。补搜及网页抓取有全局上限，既有请求总上限 1000、响应字节上限 2 GB、570 秒截止时间不提高；生产配置需从 964/1.928 GB 调整到现有上限以覆盖预算预留。
- Axel 完整回归暴露模型在 JSON 字符串中输出 Markdown `\-` 的格式错误，且单次模型修正重复了错误。增加只保留 Markdown 原文的反斜杠编码修复；不推断缺失字段、括号或截断内容。
- 报告明确区分检索输入和已核实任职，标明来源列表日期为访问日期；企业、协会人员不因进入本服务而自动被称为临床医生。文献未查到不等于本人没有论文。

部署须从本分支已提交、测试、推送的 revision 生成源码归档，叠加两个组件的构建产物到已核实的原 Worker 基础镜像。只重建 research-worker，保留既有 Gateway current/previous 与其他服务实例。部署前创建并验证 Research SQLite 和配置备份；部署后检查镜像 revision、心跳、健康、重启数、公开 API 和产物校验。原用户的历史失败任务不由探针修改。
