## 职责划分与代码

新增 `packages/research-agent/src/evidence-investigator.ts`。身份通过后，Agent 接收原始输入、已核实身份、前一步实际读取的网页片段及真实链接，自行调用 PubMed 查询、论文读取、来源分页阅读和链接阅读。它可以调整过窄查询、处理跨语言名称、判断作者归属、选择领域文献，或报告剩余证据缺口。该模块没有任何真实医生、医院、域名或译名案例表。

人物事实和文献归属先由 Agent 提议，代码检查类型、来源 ID、实际读取记录、年份范围、原文引用存在性和作者—单位元数据关系，再由独立模型复核语义。单位引用必须来自所选作者本人的记录，不能借用合作者单位。缺少作者单位时，允许使用实际读到的官方发表目录等明确佐证，且继续接受复核；仅姓名相同不足以确认。

领域文献可以来自其他作者，研究范围必须由已核实的职责或本人论文支持。科室归属不能直接包装为个人研究方向。译文事实与原文引用分开保存，固定代码不再要求中文履历是英文网页的字面子串，也不再用姓名附近的关键词认定这些事实。后续写作使用已复核履历，不能重新插入未经核验的个人事实。

NCBI 改写搜索式、删除 Author/Affiliation 条件时，新适配器保留候选和实际查询说明供 Agent 判断，避免直接把候选变成空结果；旧接口兼容逻辑保留。PubMed 元数据和 Crossref DOI 核对仍由适配器负责。可用 PMID 不因可选 DOI 佐证请求失败而整项丢弃，未被佐证的 DOI 不写入结果。

本次继续将核心证据表交给 Agent：研究设计、样本与来源、方法、结果和局限均从实际读取的论文摘要提取，逐行绑定该论文的原文引用，并由独立模型复核。代码只检查字段、篇数、所选 PMID 和引用存在性；Agent 路径不再调用旧的关键词研究设计分类。写作及修复后均使用已复核表格，不能覆盖为未经核验的分类。证据状态升为 `doctor_evidence_investigation.v2`。

完整 Agent 研究报告保留答案长度和引用等全部质量门槛，且必须完成模型复核；旧 `brief` 兼容路径中的放宽检查、提前成功或跳过复核不能算作完整 Agent 研究成功。测试仍会明确区分简化合同与真实医学合同。

试验开关沿用 `RESEARCH_IDENTITY_AGENT_ENABLED`，默认关闭；开启后已涵盖两段调查，而非仅身份。Gateway 在该开关开启时不加载/注入医生预置注册表。旧固定流程保留供关闭开关时兼容，不能因此声称所有旧路径已去掉规则。

## 预算和恢复

- 身份默认上限：4 次付费搜索、12 次页面读取、8 次模型调用。
- 资料与文献默认上限：4 次 PubMed 查询、50 次论文读取、4 次网页读取、10 次模型调用；本阶段没有 SerpAPI 工具。已读页面明确列出的 PMID 或实际 PubMed 链接可直接用于读取候选，仍须读取元数据并核验归属。
- 新流程配置为身份 8 + 证据 10 + 生成/复核 6，即默认 24 次模型调用上限。启用前必须显式提供对应 token、外部请求和至少 900000 字节状态预算；上限不是要求每次用满。
- 搜索、读取、模型调用均先持久化资源预留再执行；超时与未完成调用仍计入预算。身份与证据状态可恢复，已成功查询和已读记录可复用。DOI 佐证缓存也写入同一证据状态。
- 临时模型错误发生在第二次或更后调查调用时，不再仅因“已经调用过模型”而禁止恢复。进入报告生成后的整体恢复尚未完成，不能声称全流程已能断点续跑。
- 证据模型单次输出上限由 6000 调为 10000 token，以容纳履历、文献选择和核心证据表；配置按最坏情况预留。外部请求预算按两次尝试共享持久化调查记录计算，仅为可能中断的 Crossref 核对额外预留，避免把已完成调查假定为全部重做。

5 分钟/8 分钟按创建请求到可用结果的完整墙钟耗时计算；超过 8 分钟调查各阶段，不能将本文件的单独证据阶段耗时当作完整服务 SLA。

身份和证据 Agent 每次决策可看到从创建任务开始的耗时、5/8 分钟目标以及剩余硬截止时间，包含排队和前置阶段。目标不会改变硬截止时间，也不允许为了速度删减证据或跳过复核。
