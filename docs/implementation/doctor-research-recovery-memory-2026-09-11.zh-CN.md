## 通用改动

- **生成阶段恢复**：身份和证据状态以外，已完成的正文生成与输出复核响应也保存到所属任务的租约保护状态。复用键包含模型、阶段、调用序号、系统提示、任务提示、输出预算和推理配置。仅同一任务、同一调用内容可复用；不同调用序号仍可重新生成。外部调用前继续扣除持久化预算，恢复不会重置已用预算。复用内容仍经过完整质量检查和最终提交的租约校验。
- **调查笔记**：Agent 可自行保存带来源/PMID 的临时计划和筛选笔记，后续决策继续读取。它们不是独立证据，不能替代实际原文引用与语义复核。该机制用于减少较早工具结果离开工作窗口后的重复读取，没有医生专用内容。
- **参考文献目标**：调查阶段直接接收医学合同的 40 篇目标；3 篇仅是安全下限。未达目标须说明实际证据或资源限制，复核模型检查解释与真实查询、读取记录是否一致；不允许用无关文献凑数。
- **复核输入**：保留所选论文的完整摘要。本人论文额外提供作者名单及已选作者本人的单位记录，不重复所有合作者单位和无关书目元数据。原始完整记录仍保存在任务状态中。
- **调用序号**：模型客户端的旧 `attempt <= 9` 与新的 Agent 循环不兼容，已与存储层对齐到 1–100；实际调用仍受调查和整项持久化资源预算约束。默认证据循环改为最多 12 次模型调用，覆盖调查、格式纠正和独立复核；身份 8 + 证据 12 + 生成/复核 6，共需显式配置 26 次总预算。本次探针的每次输入上限 38000 token、总输入 1000000、总输出 300000。
- **格式纠错**：错误指向具体字段和来源 ID。仅当 `evidence.limitations` 缺失而顶层存在唯一的 `limitations` 数组时，机械移动原数组并保留修复记录；不改写其内容，也不放宽事实引用。插入省略号或翻译后的“原文引句”仍须由 Agent 纠正。
- **选题证据**：选题仍须包含官方职责页面或已核实本人论文的依据；同时允许引用实际读取的领域论文解释综述主题。不能仅因补充引用属于其他作者就机械拒绝；独立复核继续判断主题关联，也不能把领域进展写成本人研究成果。

完整报告诊断使用已有的三段并行生成能力，后续仍须独立复核。该设置目前只在隔离探针中明确启用，不能据此声称生产配置已更新或真实服务耗时已达标。
